O objetivo deste projeto é caracterizar e desenvolver sensores semicondutores do tipo LGAD para o upgrade
do experimento ATLAS, bem como para outras aplicações no âmbito do Instituto de Física da USP. O
trabalho será dividido em fases as quais visam em um primeiro momento consolidar o know how sobre essa
tecnologia, e em um segundo momento, com as competências consolidadas, contribuir para a
melhoria do sensor e suas aplicações em diversas áreas da ciência, bem como para o ATLAS.
